# Recover the authoritative protocol contract

Type: research
Status: resolved

## Question

What exact initialization, decision-response, event, and private-observation shapes must a Python agent support, and what deterministic legality fallbacks prevent faults for each decision kind?

## Answer

Use a single long-lived, standard-library JSONL loop: reply `{}` to `{"type":"init",...}`; for every `{"type":"decision","decision":{"kind":...},"history":[...],"deadlineMs":...}`, rebuild from `entry["event"]`, emit exactly one response JSON plus newline, and flush. Never emit diagnostics to stdout. The baseline establishes the eight required `kind`/response pairs: `nominate-chancellor` -> `{"type":"chancellor-nominated","target":seat}`; `vote` -> `{"type":"vote-cast","vote":"yes"|"no"}`; `president-discard` -> `{"type":"president-discarded","policy":"liberal"|"fascist"}`; `chancellor-legislate` -> `{"type":"policy-enacted","policy":...}` or `{"type":"veto-requested"}`; `president-veto-response` -> `{"type":"veto-responded","accepted":bool}`; `investigate-player` -> `{"type":"loyalty-investigated","target":seat}`; `special-election` -> `{"type":"special-election-called","target":seat}`; `execute-player` -> `{"type":"player-executed","target":seat}`; and `discuss` -> `{"type":"discussion-contributed"}`. Treat an unknown request kind as a controlled protocol error only after attempting a safe response is impossible; it must be covered by tests because a thrown exception faults the seat.

Reconstruct `seats`, own role/identity, known Fascists, known Dictator, live seats, current President/Chancellor, last elected government, policy counts, investigated targets, private presidential and chancellor policy arrays, and veto status. Initialization observation supplies the ordered seats, current President and private role knowledge (`you`, `knownFascists`, `knownDictator` in the baseline contract). Update from `president-announced`, `chancellor-nominated`, `government-elected`, `chaos-triggered`, `policy-enacted`, private `president-cards-drawn`/`chancellor-policies-received`, `loyalty-investigated`, `player-executed`, and `veto-responded`. Normalize policy values defensively: production private observations are string arrays in the baseline, while replay public policy entries can be card objects under `enacted`/`discarded`.

Legality guardrails come before tactics: for nomination, select only a live seat other than President and last Chancellor, and exclude last President while more than five live seats remain; for investigation, choose a live non-President who has not already been investigated; for special election/execution, choose a live non-President. If the strategy choice is outside that computed set, use the first clockwise legal seat from the acting seat. For policy choices, choose only a policy actually present in the current private hand; when no Liberal is present, enact/discard Fascist; request a veto only with an all-Fascist chancellor hand, at least five Fascist policies, and no immediately preceding veto rejection. Vote only `yes` or `no`; respond to a veto with a Boolean; keep discussion silent with the minimal `discussion-contributed` object. Clear private hands after enactment or accepted veto, reset term limits after chaos, and never assume replay-only global fields such as the full deck or roles are visible in a live `Visible History`.

The provided replay confirms the public event vocabulary (`game-started`, nomination, votes, legislative results, discussion, investigation, and special election) and its AI-call prompts enumerate legal choices, but it is not the per-seat runner input. Therefore, the implementation must trust reconstructed live history for behavior and use replay data only to build tests, not read global replay roles/deck.
